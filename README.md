# Greenleaf-stores-Excel-Project-
# 🌿 GreenLeaf Stores Sales & Profitability Dashboard

## 📌 Project Overview
This project analyses retail sales data for GreenLeaf Stores to understand revenue performance, product profitability, and customer purchasing trends.

The aim was to convert raw transaction data into meaningful insights that support business decision-making.

---

## ❗ Problem Statement
GreenLeaf Stores needed better visibility into:
- Sales performance  
- Product profitability  
- Customer buying patterns  
- Order fulfilment status  

Without structured reporting, it was difficult to identify high-performing products and profitable sales channels.

**Goal:** Analyse store data to generate actionable business insights.

---

## 🧠 Project Workflow

### 1️⃣ Data Cleaning
- Corrected inconsistent product and customer name formats  
- Standardized text casing  
- Checked for missing values  
- Verified numeric fields (price, cost, quantity)

### 2️⃣ Data Preparation
- Structured dataset for analysis  
- Ensured consistent product categories  
- Validated shipment status values

### 3️⃣ Analysis Performed
- Revenue calculation  
- Profit calculation (Unit Price – Unit Cost)  
- Sales by category  
- Customer purchase analysis  
- Shipment performance analysis

---

## 📊 Key Metrics
- Total Revenue  
- Total Profit  
- Quantity Sold  
- Profit by Product Category  
- Sales by State  
- Shipment Status Distribution

---

## 📈 Insights
- Identified top-selling product categories  
- Highlighted most profitable products  
- Revealed customer purchasing trends  
- Tracked delivery vs returned orders  
- Showed geographic sales distribution

---

## 🛠️ Tools Used
- Microsoft Excel / Power BI  
- Data Cleaning  
- Sales & Profit Analysis  

---

## 🏆 Outcomes
- Improved visibility into profitability  
- Identified high-margin products  
- Supported better inventory planning  
- Enabled data-driven decisions

---

## 📁 Dataset Fields

| Field Name | Description |
|-----------|------------|
| Order ID | Unique order identifier |
| Order Date | Date of purchase |
| Product Name | Product sold |
| Product Category | Product category |
| Quantity Sold | Number of units sold |
| Unit Price | Selling price per unit |
| Unit Cost | Cost per unit |
| Customer ID | Unique customer identifier |
| Customer Name | Customer name |
| Shipment Status | Delivery status |
| State | Customer location |
